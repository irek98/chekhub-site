Как выгрузить чеки из ОФД в Google Таблицы

Excel удобен одному, а отчёт часто нужен сразу нескольким людям: бухгалтеру, владельцу, управляющему точкой. Разбираем четыре способа держать чеки из ОФД в Google Таблицах — от импорта CSV за пять минут до скрипта, который обновляет лист сам.

Зачем вообще Google Таблицы, если есть Excel

Причина обычно одна: к таблице нужен доступ нескольким людям — бухгалтеру, владельцу, управляющему точкой. Файл Excel по почте быстро превращается в пять версий, а таблица с общей ссылкой остаётся одной. Второй сценарий — автоматическое обновление: скрипт дописывает строки, и отчёт всегда свежий.

Способ 1: импорт CSV — пошагово

  1. В кабинете ОФД выгрузите отчёт по чекам в CSV или Excel за нужный период.
  2. В Google Таблицах: Файл → Импорт → Загрузка, выберите файл.
  3. Тип разделителя ставьте «Определять автоматически»; если колонки съехали — выберите точку с запятой или запятую вручную.
  4. Проверьте три вещи: дата осталась датой, суммы не превратились в текст, длинные ФД не стали «1,23E+12».

Последний пункт — самая частая проблема. ФД и ФПД — длинные числа, и таблица любит показывать их в экспоненциальной форме. Лечится форматом ячейки «Число → 0 знаков» или импортом колонки как текста.

Способ 2: регулярная выгрузка файла в папку Drive

Схема без программирования внутри Google: на компьютере по расписанию формируется CSV (вручную, макросом или небольшим скриптом), файл кладётся в папку, синхронизированную с Google Drive. В таблице данные подтягиваются формулой импорта.

Важно: у кабинетов ОФД обычно нет публичной ссылки на CSV, поэтому формула =IMPORTDATA("https://…") работает только если файл лежит в доступном месте — например, опубликован из Drive. Прямую ссылку кабинета она не заменит.

Способ 3: Apps Script и API ОФД

Если у вашего ОФД есть API и доступ к нему входит в тариф, таблица может забирать данные сама. Логика скрипта простая: получить документы за период, разложить по колонкам, дописать в лист, не задваивая строки.

function pullChecks() {
  var sheet = SpreadsheetApp.getActive().getSheetByName('Чеки');
  var from = sheet.getRange('B1').getValue();   // дата начала
  var to   = sheet.getRange('B2').getValue();   // дата конца
  var url = API_URL + '?from=' + from + '&to=' + to;
  var resp = UrlFetchApp.fetch(url, {
    headers: { 'Authorization': 'Bearer ' + API_KEY }
  });
  var data = JSON.parse(resp.getContentText());
  data.documents.forEach(function (d) {
    sheet.appendRow([d.date, d.kassa, d.type, d.sum, d.fd, d.fpd]);
  });
}

Что нужно предусмотреть до запуска: ключ API хранить в свойствах скрипта, а не в коде; проверять, не добавились ли уже эти ФД; ставить триггер раз в сутки, а не каждые пять минут — у ОФД бывают лимиты запросов.

Подводные камни

  • Кодировка. Если вместо русских букв «кракозябры», CSV был в Windows-1251 — пересохраните в UTF-8.
  • Разделитель. Русская локаль Excel любит точку с запятой, Google — запятую. Проверяйте после импорта, а не до.
  • Лимит ячеек. Google Таблицы держат до 10 млн ячеек на файл: чеки за год по сети касс могут не влезть в один лист — делите по месяцам.
  • Дубли. При повторном запуске скрипта строки задваиваются, если не проверять ФД. Это самая частая ошибка в автоматизации.
  • Права доступа. Ссылка «всем, у кого есть ссылка» удобна, но для выручки и ФН лучше ограничить круг людей.

Если автоматизация нужна, но возиться со скриптами не хочется, выгрузку можно заказать: файл или таблица будут обновляться по расписанию без вашего участия.

Частые вопросы

Можно ли подключить Google Таблицы к кабинету ОФД напрямую?

Только через API, если оператор его предоставляет и доступ входит в тариф. Публичной ссылки на CSV у кабинетов обычно нет, поэтому формула IMPORTDATA сама по себе не сработает.

Почему после импорта ФД отображается как 1,23E+12?

Таблица приняла длинное число за числовой формат. Поставьте для колонки формат «Число → 0 знаков» или импортируйте её как текст.

Как не задвоить строки при автоматической выгрузке?

Перед добавлением проверяйте ФД: если такой документ уже есть на листе, строку пропускают. Без этой проверки повторный запуск скрипта удвоит данные.

Сколько чеков помещается в одну таблицу?

Ограничение Google Таблиц — около 10 млн ячеек на файл. Если чеков много, делите данные по месяцам или по кассам на отдельные листы.

Нужна помощь с выгрузкой?

Соберём чеки из ОФД в Excel/CSV или загрузим данные в 1С — от 1 500 ₽. Пришлите ОФД, количество касс и период.
