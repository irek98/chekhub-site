Как выгрузить чеки из Такском ОФД: кабинет, Excel и API

В ОФД Такском чеки лежат в личном кабинете lk-ofd.taxcom.ru: там же формируется отчёт по продажам за период и сохраняется в Excel. Ниже — что именно есть в кабинете, в каком порядке выгружать данные по нескольким кассам, как проверить файл перед передачей бухгалтерии и что делать, если нужны позиции чеков, а не только суммы.

Порядок, который экономит больше всего времени: сначала список касс и границы периода, потом выгрузка по одной кассе, потом сверка трёх цифр — количество чеков, приходы, возвраты. Только после этого файл идёт в работу.

Что есть в кабинете Такском

Кабинет ОФД Такском («Такском-Касса») — это не только список чеков. Для выгрузки важны три вещи: документы по кассам, отчёт по продажам и доступ к API для тех, кому нужна регулярная выгрузка.

Интерфейс кабинета обновляется, поэтому названия пунктов меню могут отличаться от того, что вы видите у себя. Ориентируйтесь на смысл: раздел с кассами, раздел с документами и отчёт с выгрузкой в файл.

Шаг 1. Зафиксируйте, что именно нужно выгрузить

Пока не определены четыре параметра, любая выгрузка превращается в переделку:

  • Период — с какого по какое число и в каком часовом поясе (по поясу точки, не сервера).
  • Кассы — заводские номера или РН ККТ, для сети ещё и названия точек.
  • Тип документов — только приходы или приходы вместе с возвратами и коррекциями.
  • Состав — нужны только шапки чеков (дата, сумма, ФН, ФД) или ещё и позиции с наименованиями товаров.

Если файл нужен бухгалтерии, уточните у неё формат заранее: одним листом или отдельными листами по кассам, какие колонки обязательны. Переделывать структуру после выгрузки дольше, чем сразу договориться.

Шаг 2. Выгрузите отчёт по продажам

  1. Войдите в кабинет и выберите кассу (или точку, если кабинет умеет свод по нескольким ККТ).
  2. Откройте раздел с отчётами по продажам и задайте период из шага 1.
  3. Сформируйте отчёт и сохраните его в Excel.
  4. Проверьте дату последнего документа в файле — она должна совпадать с концом периода. Если раньше, файл обрезан по числу строк: выгрузите остаток отдельным интервалом.
  5. Повторите для каждой кассы и назовите файлы по схеме 2026-09_kkt-0001234567.xlsx.

Когда касс несколько, не смешивайте файлы в одну папку без пометки — через месяц невозможно понять, откуда строки. Если кабинет отдаёт сводный отчёт по всем кассам, проверьте, есть ли в нём колонка с ККТ: без неё выручку по точкам не разделить.

Шаг 3. Проверьте файл перед работой

Проверка занимает пять минут и почти всегда находит хотя бы одну проблему. Минимальный набор:

Что проверитьНормаПризнак проблемы
Количество чековСовпадает с кабинетом за тот же периодМеньше — файл обрезан или не тот период
Сумма приходовСходится с отчётом по кассеРасхождение — потерян день или задвоены строки
ВозвратыИдут отдельными строкамиПриплюсованы к приходам — выручка завышена

Колонки с номером фискального накопителя и номером документа нужно импортировать как текст. Иначе Excel округлит длинное число, и связка ФН + ФД + ФПД перестанет работать — дубли вы уже не отфильтруете.

Если нужны позиции чеков

Отчёт по продажам почти всегда отдаёт шапки документов: дата, сумма, касса, тип операции. Позиции — это отдельные строки внутри чека: наименование, количество, цена, сумма по строке. Без них не собрать отчёт по товарам и не сверить остатки.

  • Проверьте, есть ли в кабинете отчёт с составом чека. Иногда он есть, но называется иначе: «товары», «номенклатура», «детализация».
  • Если отчёта нет — нужен API. В кабинете есть раздел для разработчиков с описанием методов: там документы забираются программно, вместе с составом.
  • Третий вариант — сервис выгрузки. Он собирает чеки с позициями в готовый Excel под вашу структуру: по кассам, точкам, сменам и товарам.

Выгрузка через API: когда это оправдано

Ручной отчёт нормально работает, пока выгрузка нужна раз в месяц и касса одна-две. API стоит подключать, если выполняется хотя бы одно условие:

  • выгрузка нужна каждую неделю или каждый день;
  • касс больше трёх и период приходится дробить на части;
  • данные должны попадать сразу в 1С, Google Sheets или сводную таблицу;
  • нужны позиции чеков, которых нет в готовом отчёте.

Схема работы скрипта простая: авторизация → запрос документов частями (по дням или сменам) → сборка в таблицу → проверка дублей по связке ФН + ФД + ФПД → сохранение файла и, если нужно, отправка в Telegram или на почту по расписанию. Подробнее о способах — в статье как выгрузить чеки из ОФД в Excel.

Типичные ошибки

  • Отчёт за «месяц», а в файле 28 дней. Период обрезан лимитом строк — проверяйте дату последнего документа, а не только итог.
  • Задвоение при склейке. Два отчёта с пересекающимися датами дают двойные строки: удаляйте дубли по ФН + ФД + ФПД.
  • Кракозябры в CSV. Файл в Windows-1251 открыт как UTF-8 (или наоборот) — выбирайте кодировку при импорте, а не «исправляйте» текст руками.
  • Незакрытая смена. Последние чеки периода остаются в открытой смене и не попадают в свод — закройте смену и выгрузите заново.
  • Переходящая смена. Выручка не сходится ровно на одну смену: считайте по дате чека, смены сверяйте отдельно.
  • Нет колонки с точкой. При склейке файлов нескольких касс теряется привязка к магазину — добавляйте ККТ сразу.
Самая частая причина «не сходится с 1С» — не ошибка выгрузки, а разные правила отбора: где-то считают с возвратами, где-то без, где-то берут дату смены вместо даты чека. Сначала договоритесь о правиле, потом сверяйте цифры.

Частые вопросы

Где в ОФД Такском выгрузить чеки в Excel?

В личном кабинете lk-ofd.taxcom.ru: отчёт по продажам формируется за выбранный период и кассу и сохраняется в Excel. Если нужны данные, которых в отчёте нет (например, позиции), их забирают через API или через сервис выгрузки.

За какой период доступен отчёт по чекам?

Фискальные документы оператор хранит не менее пяти лет, но готовый отчёт в кабинете обычно ограничен периодом и числом строк. Длинный интервал делят на части и склеивают файлы. Точные лимиты зависят от тарифа.

Можно ли выгрузить позиции чеков?

Позиции — отдельные строки внутри чека. Если в файле их нет, значит выгружены только шапки документов: состав чека забирают через API оператора либо через сервис, который собирает чеки вместе с наименованиями.

Есть ли у Такском API?

Да, в кабинете есть раздел для разработчиков с описанием API. Через него документы забирают частями и строят выгрузку по расписанию — это удобнее ручных отчётов, когда касс несколько или выгрузка нужна часто.

Почему суммы не сходятся с 1С?

Обычные причины: не учтены возвраты и коррекции, обрезан последний день периода, часть чеков осталась в незакрытой смене, файлы выгружены в разных часовых поясах. Сверяйте по количеству чеков и дате последнего документа, а не только по итоговой сумме.
