Как выгрузить чеки из Первого ОФД (1-ОФД) в Excel

Чеки из Первого ОФД доступны в личном кабинете lk.1-ofd.ru. Кроме самого кабинета у оператора есть «Контроль выручки» (сводки о продажах без входа в кабинет) и модуль синхронизации с 1С. Ниже — в каком порядке выгружать документы, чем эти способы отличаются, как проверить файл и что делать, если нужны не суммы, а позиции чеков.

Разница между способами проста: кабинет даёт построчный список документов, «Контроль выручки» — готовые сводки, синхронизация с 1С — сразу данные в учётной системе. Для отчёта бухгалтерии нужен первый вариант, для ежедневного контроля выручки хватает второго.

Названия разделов в кабинете могут отличаться от привычных: интерфейс обновляется, а у разных тарифов набор отчётов разный. Ищите по смыслу — «документы», «отчёты», «продажи», «выгрузка».

Шаг 1. Подготовьте данные для выгрузки

  • Список касс — заводские номера или РН ККТ. В сети сразу отметьте, какая касса к какой точке относится.
  • Период — даты начала и конца и часовой пояс точки (не сервера).
  • Тип документов — только приходы или приходы с возвратами и коррекциями.
  • Формат результата — если файл идёт в бухгалтерию, уточните обязательные колонки и разбивку по листам.

Права доступа тоже стоит проверить заранее: в кабинете может быть несколько пользователей, и не у каждого есть право на выгрузку документов. Если отчёт не формируется, проблема часто именно в роли пользователя, а не в периоде.

Шаг 2. Выгрузите отчёт из кабинета

  1. Войдите в кабинет и выберите кассу.
  2. Откройте раздел с документами или отчётами по продажам.
  3. Задайте период и тип документов, сформируйте отчёт.
  4. Сохраните файл, назвав его по схеме 2026-09_kkt-0001234567.xlsx.
  5. Проверьте дату последнего документа: если она раньше конца периода, отчёт обрезан по числу строк — выгрузите остаток.
  6. Повторите для каждой кассы и добавьте колонку с точкой при склейке.
Если касс больше двух-трёх, ручная выгрузка быстро превращается в рутину: каждый месяц одни и те же шаги и одни и те же ошибки при склейке. В этом случае выгоднее один раз настроить выгрузку скриптом — по API и расписанию.

Шаг 3. «Контроль выручки» — когда кабинет не нужен

Этот сервис присылает данные о продажах автоматически, без входа в личный кабинет. Он хорошо закрывает вопрос «сколько пробили вчера и сколько за неделю», но у него есть границы:

  • это сводки, а не документы — отдельный чек по нему не восстановить;
  • нет позиций — отчёт по товарам на таких данных не построить;
  • структура фиксированная — под требования бухгалтерии её придётся пересобирать.

Поэтому схема обычно такая: «Контроль выручки» — для ежедневного контроля, выгрузка из кабинета или API — для отчётов и сверок.

Если нужны позиции чеков

Позиции — строки внутри чека: наименование, количество, цена, сумма. Они нужны для отчёта по товарам, сверки остатков и анализа ассортимента. Способы получить их:

  • отчёт с детализацией в кабинете — если он есть в вашем тарифе;
  • API оператора — документы забираются программно, вместе с составом;
  • сервис выгрузки — приходят готовые таблицы по кассам, сменам и товарам.

Как устроена работа с составом чека и как проверить, что приехали все наименования — в отдельной статье выгрузка чеков с позициями.

Типичные ошибки

  • Отчёт за месяц, а в файле меньше дней. Кабинет ограничил число строк — делите период на интервалы.
  • Склейка с пересечением дат. Один и тот же день в двух файлах даёт двойную выручку: удаляйте дубли по связке ФН + ФД + ФПД.
  • Незакрытая смена. Чеки в открытой смене не попадают в свод — смена должна быть закрыта.
  • Разные часовые пояса. Кассы в разных регионах: после склейки чеки первых и последних чисел «съезжают» на день.
  • Роль пользователя без прав. Отчёт не формируется не из-за периода, а из-за прав в кабинете.
Проверяйте выгрузку по трём цифрам: число чеков, сумма приходов, сумма возвратов. Если все три совпали с кабинетом — файл можно отдавать. Если нет, ищите стык интервалов, а не пересчитывайте всё заново.

Частые вопросы

Где в Первом ОФД выгрузить чеки в Excel?

В личном кабинете lk.1-ofd.ru: выберите кассу и период, сформируйте отчёт по документам и сохраните его в файл. Для регулярных сводок есть сервисы оператора, которые передают данные о продажах без входа в кабинет.

Что такое «Контроль выручки»?

Сервис автоматической передачи данных о продажах: сводки приходят сами, без доступа в личный кабинет. Удобно для ежедневного контроля, но это агрегированные данные, а не построчный список чеков с позициями.

Как загрузить чеки в 1С?

У оператора есть модуль синхронизации ОФД с 1С — он загружает данные по чекам в учётную систему. Если конфигурация его не поддерживает, данные переносят через выгрузку в Excel или через API.

Можно ли выгрузить позиции чеков?

Если в отчёте есть только шапки документов — нужен API или сервис выгрузки: они забирают состав чека и собирают его в таблицу по товарам.

За какой срок доступны чеки?

Фискальные документы оператор хранит не менее пяти лет, но выгрузка из кабинета ограничена периодом и числом строк. Длинный период делят на интервалы и склеивают файлы.

Нужна выгрузка чеков из Первого ОФД?

Соберём чеки в Excel или загрузим в 1С: по кассам, точкам, сменам и товарам, с проверкой дублей и сверкой сумм. От 3 000 ₽.
